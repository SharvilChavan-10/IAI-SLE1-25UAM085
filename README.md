# AI Study Assistant - Basic Rule-Based Agent

## Course

02UAML204 - Introduction to Artificial Intelligence

## Objective

The objective of this project is to demonstrate an
AI-augmented coding workflow using GitHub Copilot.

The project implements a basic rule-based conversational
AI agent that can interact with the user and perform
simple task-management actions.

## AI Tool Used

GitHub Copilot Chat

## Technologies

- Python
- Visual Studio Code
- Git
- GitHub
- GitHub Copilot

## Features

- Greeting responses
- How are you response
- Thank-you response
- Help command
- Task creation
- Task listing
- Task completion
- Exit using bye

## Agent Workflow

The agent receives a user request, identifies the
appropriate predefined intent, performs the corresponding
action, and returns a response.

Example:

User:
add task Study Python

Agent:
Added task: Study Python
